# Evaluation: structure is not truth

## Content

Every required question must have an answer or an explicit explanation of insufficient material. Keep decisive conditions visible with conclusions; distinguish fact, inference and unknown. Do not erase conflicts by merging or add empty branches for symmetry. Check a sample of ordinary facts and all high-risk numbers, formulas, negations and decision-critical evidence against sources.

## Resources and coverage

Crops retain legends, units and qualifying footnotes. Generated images are not source screenshots. Table values align; equations remain editable and correct; attachment names explain their role. Missing media tools are a gap, not a passed check.

Full-collection review requires coverage accounting, not only top-k retrieval. Partial transcripts, frames or pages must remain partial. Exclusions need justification. Included originals must have valid portable paths and hashes; missing originals must be declared.

## Engineering

Run preflight, strict compile and delivery validation, then validate from another location. Only an actual native open/edit/save/reopen can justify `native_runtime=passed`.

For long tasks exercise committed-state recovery, expired leases, idempotency, source/goal invalidation, cooperative concurrency, stale-room summaries, small recovery packets, reasoned rereading, pagination, corruption rejection and consistent backup. No silent database erasure.

For Context Atlas, check that unacknowledged/reset sessions receive full bodies, critical known qualifiers cannot be dropped for budget or hidden visibility, changed visual input invalidates review even with identical text, and stale bindings block compilation.

## Cost

Compare only quality-passing candidates. Record actual input, output, cached-input subset, retries, tool payload and validation costs. UTF-8 bytes and synthetic scheduling experiments are not API token bills.

Useful measures include reliable required-question coverage, major omissions/errors, evidence reachability, reasons for repeated source returns, successful recovery and supported information per measured token. Shortness alone is not success.

## Reproducibility

Run `python scripts/run_tests.py`; use `--out NEW_DIRECTORY` to preserve an actual local result. Optional dependency gaps are skips. Follow `docs/testing.md` for synthetic demonstrations and native acceptance. No model calls means no new model blind test or real-world quality comparison was performed.
