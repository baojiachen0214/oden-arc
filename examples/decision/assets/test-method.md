# 试验记录与计算约定
所有记录为合成数据。
clear_bottle = 透明瓶；crumpled_bottle = 压扁瓶。
四批图像不是同一批，照明和设备一致，未做随机配对实验。
每行 correct 是该行 total 张图像中分类正确的张数。
总体正确率 = 各组 correct 之和 / 各组 total 之和，总样本数必须大于 0。
若估计各类各占一半的场景，可把两类条件正确率各赋权 1/2；该估计假设这些小批次的类内表现可迁移，不能替代指定的同批复测。
Rook v2 透明瓶批次被两个说明材料重复引用，这不增加样本数。
旧版 Sable v0 曾有平均耗时 92 ms 的记录，版本和计时范围与当前测试不一致。
