# 合成教学材料：简单指数平滑

这份材料与数据专供技能演示，不是用户实验或真实研究结果。

## 更新规则
令 y_t 为本期观测，l_t 为更新后的水平，采用 l_t=alpha*y_t+(1-alpha)*l_(t-1)。本示例设 0<alpha<1，初值 l_1=y_1。

## 参数
alpha 越大，当前观测在本次更新中权重越大。不同 alpha 在跟随变化与平滑波动之间有不同表现；本材料没有给出能够确定最优 alpha 的验证集和损失函数。

## 边界
这里的简单模型没有独立的趋势项或季节项。不要从这个公式推断它显式建模了趋势或季节性。

## 算一次
若上一期水平=100，本期观测=120，alpha=0.3，则新水平=0.3*120+0.7*100=106。
