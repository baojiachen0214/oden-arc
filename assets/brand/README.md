# OdenMap brand assets

These are renditions of the official OdenMap app icon, used to identify this companion project and link to [OdenMap](https://baojiachen0214.github.io/oden-website/). The same icon works on light and dark backgrounds; the `logo-dark*.png` names remain available for existing consumers.

The product icon is separate from ARC’s MIT-licensed code, prompts, documentation and synthetic examples. These branding files are not licensed under MIT and do not grant ownership of the OdenMap name or imply endorsement of a fork. The OdenMap application remains closed source.

All PNGs have transparent corners and no embedded metadata. No application source or signing assets are included.
