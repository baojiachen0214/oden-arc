# Scope of this repository

Oden ARC is a standalone tool for organizing evidence and creating OdenMap files. The repository license covers its original code, prompts, documentation, synthetic examples, not the separate closed-source OdenMap application, the product icon in assets/brand/, or third-party dependencies.

Compatibility field names and file-layout details are included only to implement the public adapter. Application implementation, project files and private source history are not distributed here.

The names OdenMap and Oden ARC identify their respective projects. The MIT license is not an endorsement of a fork or permission to imply official affiliation. Third-party component licenses remain in force; see THIRD_PARTY.md.

Synthetic examples illustrate behavior and limitations. They are not real customer records, production findings, model-quality benchmarks or evidence that a native application was executed.
